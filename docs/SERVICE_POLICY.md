# イベナウ サービス方針・開発方針（2026-11 決定）

## 最終目標
「イベント当日の混雑情報を共有する全国規模の情報インフラ」。コンセプトは **「イベント会場の今がわかる。」**

## 集客
Google 検索が中心。知名度づくりは最初の目標にしない。狙う検索語の例：
- ○○花火大会 シャトルバス／駐車場／駐車場 混雑／トイレ／帰り 渋滞
- ○○祭り 交通規制 ／ ○○フェス 駐車場 空き状況

## 優先度
| 高（最優先） | 低・対象外 |
|---|---|
| 自動収集（検索流入のため） | 全国イベントマップ・開催中イベントの地図表示 |
| 詳細ページの生成・更新 | 現在地周辺検索（利用者の位置情報は使わない） |
| SEO最適化 | 地域別の探索・地図中心の検索UI |
| 駐車場・トイレ・飲食・シャトルバス・道路の表示 | 過度な広告 |
| かんたんな投稿（選択式ワンタップ） | 不要な会員登録・ポイント |
| 鮮度管理 | |

## イベント詳細ページ（いちばん大事なページ）
- 基本情報：イベント名・開催日・会場/住所・公式サイト・アクセス・駐車場・シャトルバス・交通規制/周辺道路・トイレ・飲食エリア
- 投稿の5分類：1 駐車場 2 トイレ 3 飲食エリア 4 シャトルバス 5 周辺道路
- **公式情報と利用者の投稿をはっきり分ける**。投稿が無ければ「現在の投稿情報はありません」、確認できない項目は「未確認」。
  投稿には時刻を必ず出し、古い情報を新しく見せない。

## SEO
- 「イベント名＋駐車場／シャトルバス／トイレ／渋滞／交通規制」で見つかるページにする。
- 似た内容のページを量産しない。情報が十分なときだけ独立ページにし、それ以外は詳細ページ内の見出しで扱う。
- 重点：タイトル・見出し構造・固有の情報・説明文・構造化データ・スマホ表示・表示速度・内部リンク。

## 広告
「情報が主役。広告は脇役。」
- 禁止：全画面広告・ポップアップ・閉じにくい広告・大きな追従広告・投稿ボタンや状況を隠す広告・本文と見分けにくい広告
- 置くならページ下部・関連情報の下・地域スポンサー枠・周辺の飲食店/宿泊など。必ず「広告」「PR」と明示。
- 初期は広告収入を優先しない。

## 追記（2026-11）
- 飲食・屋台の混雑は扱わない（運営者の判断：来場者があまり困らないため）。カードと投稿の分類は 駐車場・シャトルバス・トイレ の3つ（交通規制は駐車場カード内）。
